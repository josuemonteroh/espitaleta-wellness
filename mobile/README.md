# Mobile

## Overview

This directory is reserved for the future mobile applications of the Espitaleta Wellness platform.

The mobile solution will extend the platform beyond the web application, allowing patients and healthcare professionals to securely access healthcare information from mobile devices.

Although mobile development has not yet started, the project architecture has been designed to support future native or cross-platform applications.

---

## Planned Features

Future mobile applications may include:

- Secure Authentication
- Patient Dashboard
- Health Metrics
- Nutrition Tracking
- Medical History
- Appointment Management
- Notifications
- Health Synchronization
- Offline Support

---

## Planned Technologies

Potential technologies include:

- Flutter
- Android
- iOS
- FastAPI
- PostgreSQL
- Docker
