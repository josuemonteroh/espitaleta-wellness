# Screenshots

## Overview

This directory contains screenshots of the Espitaleta Wellness platform.

These images are used to document the application's evolution, illustrate implemented features and support technical documentation, presentations and the project repository.

---

## Recommended Content

Screenshots may include:

- Login
- Dashboard
- Patient Management
- Nutrition Module
- Reports
- Mobile Interfaces
- Future Features

---

## Naming Convention

Use descriptive file names such as:

```text
login.png
dashboard.png
patients.png
reports.png
```

Avoid generic names such as:

```text
image1.png
screenshot.png
final.png
```

---

## Current Status

This directory has been prepared to store screenshots of the application as new features are developed.
