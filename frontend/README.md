# Frontend

## Overview

This directory contains the frontend application of the Espitaleta Wellness platform.

The frontend provides the user interface for healthcare professionals and patients, following a modular architecture based on reusable components, page-specific styles and organized JavaScript modules.

The current implementation represents the enterprise prototype of the platform and has been designed to support future integration with the backend API developed in FastAPI.

---

## Directory Description

### assets/

Fonts, icons, images and branding resources.

### components/

Reusable frontend components.

### css/

Application styles organized into base styles, reusable components, layouts and page-specific styles.

### js/

JavaScript modules responsible for application behavior, configuration and page functionality.

### layouts/

Shared layout resources used across multiple pages.

### pages/

HTML pages that compose the application interface.

### services/

Future communication layer with the backend REST API.

### utils/

Reusable utility functions shared across the frontend.
