# Documentation

## Overview

This directory contains the technical documentation and supporting resources for the Espitaleta Wellness platform.

It centralizes all project documentation generated throughout the planning, design, development and maintenance phases, providing a single location for architectural references, technical specifications, contracts, diagrams, research material and project artifacts.

---

## Directory Structure

```text
docs/
│
├── api/
├── architecture/
├── contracts/
├── database/

├── mockups/
├── plannings/
├── research/
└── README.md
```

---

## Directory Description

### api/

API documentation, endpoint specifications and integration references.

### architecture/

System architecture diagrams, technical designs and infrastructure documentation.

### contracts/

Functional and technical requirements for the frontend, backend and database components.

### database/

Reference database documentation, preliminary SQL scripts, design proposals and other database-related resources. Files stored in this directory are intended for documentation and planning purposes and are not considered the official database implementation.

### diagrams/

Entity-relationship diagrams, UML models and other technical diagrams.

### meetings/

Meeting notes, project decisions and follow-up documentation.

### mockups/

User interface prototypes, design concepts and visual resources.

### plannings/

Project planning, milestones, schedules and development roadmaps.

### research/

Research documents, technical studies and supporting reference material.

---

## Current Status

The documentation structure has been prepared to support the continuous evolution of the Espitaleta Wellness platform.

All technical documentation, architectural decisions, planning artifacts and reference materials should be organized within this directory to maintain consistency throughout the project lifecycle.
