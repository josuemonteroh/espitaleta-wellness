# ESPITALETA WELLNESS

## Initial Professional Prototype

Espitaleta Wellness is a healthcare technology project developed at **SparkByte Technologies** to support patient monitoring, clinical information management, biometric tracking, and healthcare workflows.

This repository represents an **early development stage of the project**, where the initial frontend interfaces, technical structure, development environment, and platform architecture were explored and implemented.

During this stage, the frontend was developed primarily with **HTML5, CSS3, and JavaScript**, alongside the initial definition of the platform's backend, database, Docker infrastructure, and future healthcare integrations.

Following this prototype stage, the project went through a technical review and evolution process. Development subsequently continued within the company's formal repository using a more production-oriented architecture, including **Angular and TypeScript** for the frontend.

The current production-oriented codebase is maintained separately and is not included in this repository.
